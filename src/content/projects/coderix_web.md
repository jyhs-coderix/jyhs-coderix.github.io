## 소개

이 웹사이트는 동아리의 활동 기록, 개발 굴, 공지, 프로젝트를 한곳에 모아두기 위해 제작한 공식 아카이브 사이트입니다.

## 주요 기능

- 활동 기록, 개발 글, 공지 글 분류
- 프로젝트 목록과 프로젝트 상세 페이지
- 태그별 글 모아보기
- 사이트 내 검색
- 홈 화면의 오늘의 프로젝트 랜덤 소개

## 사용 기술

- Astro
- Markdown
- TypeScript
- CSS
- Github Pages
- Github Actions

## 제작 과정

저의 첫 프로젝트로 동아리 소개와 활동들을 소개하고 보여주는 웹사이트를 제작했습니다
글 종류를 활동 기록, 개발 글, 공지로 나누고, 프로젝트를 별도로 관리할 수 있도록 만들었습니다

그리고 아버지의 피드백을 받아 요즘 올라오고 있다는 astro를 이용해 보았습니다.

## 배운점

워드프레스 같은걸 안써도 꽤 나쁘지 않은 블로그를 만들 수 있다는걸 알았습니다.
